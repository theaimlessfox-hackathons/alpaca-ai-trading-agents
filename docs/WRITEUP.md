# ThetaGate — one page

ThetaGate is an autonomous **paper-only** options desk. It sells defined-risk **credit spreads** when ATM implied vol is rich versus 20-day realized vol, and stands down in cheap vol or a simple breakout. It does not take unlimited short premium and does not let the model place orders.

**AI logic.** Each cycle the desk discovers names from Alpaca market data (most-actives + movers), not a hardcoded SPY/QQQ/IWM list. Warrants, OTC, levered products, and names under $10 are dropped; a failed discover is an empty book, never a silent fallback. Python then fetches bars and a DTE-banded chain, derives missing IV/delta with Black–Scholes, and gates on IV/RV ≥ 1.2. Only surviving short/long candidates go to the model. Featherless proposes a two-leg `TradeProposal`; malformed JSON is retried (≤3) and, if `XAI_FALLBACK` is on, handed to Grok. A short critic can challenge the idea; it cannot approve or spend. The model never sees `place_option_order`.

**Risk gates.** Python independently recomputes max loss `(width − credit) × 100 × qty`, DTE 7–21, short delta 0.20–0.30, long 0.10–0.15, bid–ask width, IV sanity, per-name and book caps (max 3 structures, 2 per underlying), daily −3% and total −8% equity halts, cooldown, and a file kill switch (`logs/KILL`). Invalid proposals are stored as vetoes. Entry is a day limit at the **natural** credit (short bid − long ask) so an approved ticket can fill. `PENDING_ENTRY` becomes `OPEN` only after Alpaca reports `filled_qty > 0`. Halt cancels unfilled entries, reconciles, then flattens live exposure; it stays incomplete until both pending and open risk are gone. Closes are an atomic debit sized to reconciled `open_qty`, not a copied opening credit.

**Alpaca infra.** Official MCP (`alpaca-mcp-server`) for account, clock, bars, chain, news, and multi-leg `place_option_order` (`qty` + OCC `symbol`/`ratio_qty`, `limit_price` credit negative). Market-data REST is used for the screener and snapshots. CLI is one read (`alpaca account`) for the stack requirement. Paper only (`ALPACA_PAPER_TRADE=false` is rejected). Submit is fail-closed on `EXPECTED_ACCOUNT_ID` vs live `account_number`. Railway runs the Streamlit desk and the `--live` scheduler together; the desk is monitor + STOP, not the trader.
